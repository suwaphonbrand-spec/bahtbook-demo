# BahtBook Finance — ตัวทดลองใช้

แอพบันทึกรายรับรายจ่าย งบประมาณ และรายงานการเงินส่วนตัว เปิดใช้ได้ทันทีในเบราว์เซอร์
ไม่ต้องสมัคร ไม่ต้องล็อกอิน ไม่มีค่าใช้จ่าย

**เปิดใช้งาน:** https://suwaphonbrand-spec.github.io/bahtbook-demo/

## ข้อมูลของคุณอยู่ที่ไหน

ทุกอย่างที่คุณบันทึกเก็บอยู่ใน **เบราว์เซอร์ของเครื่องคุณเองเท่านั้น**
ไม่มีการส่งขึ้นเซิร์ฟเวอร์ ไม่มีใครเห็น และเจ้าของแอพก็เข้าถึงไม่ได้

เพราะอย่างนั้นจึง **ไม่ซิงก์ข้ามเครื่อง** และข้อมูลจะหายถ้าล้างข้อมูลเบราว์เซอร์
ถ้าอยากเก็บไว้ ใช้ปุ่มสำรองข้อมูลในหน้าตั้งค่าเพื่อบันทึกเป็นไฟล์

## ลองอะไรได้บ้าง

เปิดมาจะมีข้อมูลตัวอย่างให้ดูหน้าตาก่อน กดปุ่ม "ลบข้อมูลตัวอย่าง" เพื่อเริ่มของจริง

- บัญชีเงินสด ธนาคาร บัตรเครดิต การลงทุน หนี้สิน รองรับหลายสกุลเงิน
- รายรับ รายจ่าย โอนระหว่างบัญชี แยกหมวดในรายการเดียว แท็ก กระทบยอด
- งบประมาณรายหมวด ยกยอดเหลือไปเดือนถัดไป คัดลอกงบเดือนก่อน
- รายการประจำที่ลงให้อัตโนมัติเมื่อถึงกำหนด
- รายงาน 5 แบบ แยกตามหมวด รายรับ-รายจ่าย มูลค่าสุทธิ ร้านที่จ่ายมากสุด กระแสเงินสด
- นำเข้า/ส่งออก CSV สำรองและกู้คืนข้อมูล ล็อกด้วย PIN โหมดมืด ไทย-อังกฤษ

ใช้ได้ทั้งคอมและมือถือ บนมือถือกด "เพิ่มไปยังหน้าจอโฮม" เพื่อใช้เหมือนแอพได้
