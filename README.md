# Budget &amp; Finance

แอพบันทึกรายรับรายจ่าย งบประมาณ และรายงานการเงินส่วนตัว เปิดใช้ได้ทันทีในเบราว์เซอร์
ไม่มีค่าใช้จ่าย ใช้ได้ทั้งคอมและมือถือ

**เปิดใช้งาน:** https://suwaphonbrand-spec.github.io/bahtbook-demo/

## ข้อมูลของคุณอยู่ที่ไหน

**แอพนี้ไม่มีเซิร์ฟเวอร์** ไม่มีฐานข้อมูลกลาง และผู้ทำแอพไม่เห็นข้อมูลของใครเลย

- **เข้าสู่ระบบด้วย Google** — ข้อมูลถูกเก็บเป็นไฟล์เดียวใน **Google Drive ของคุณเอง**
  และตามไปทุกเครื่องที่คุณเข้าสู่ระบบด้วยบัญชีเดียวกัน ข้อมูลวิ่งจากเบราว์เซอร์ของคุณ
  ไป Google โดยตรง
- **ไม่เข้าสู่ระบบก็ใช้ได้** — ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเครื่องเดียว ไม่ซิงก์
  และจะหายถ้าล้างข้อมูลเบราว์เซอร์ สำรองเป็นไฟล์ได้ในหน้าตั้งค่า

แอพขอสิทธิ์ Google เพียงอย่างเดียวคือ `drive.file` ซึ่งเห็นได้**เฉพาะไฟล์ที่แอพนี้สร้างเอง**
ไฟล์อื่นทั้งหมดใน Drive ของคุณมองไม่เห็น

## ทำอะไรได้บ้าง

เปิดมาครั้งแรกจะมีข้อมูลตัวอย่างให้ดูหน้าตาก่อน กดปุ่ม "ลบข้อมูลตัวอย่าง" เพื่อเริ่มของจริง

- บัญชีเงินสด ธนาคาร ออมทรัพย์ บัตรเครดิต การลงทุน หนี้สิน รองรับหลายสกุลเงิน
- รายรับ รายจ่าย โอนระหว่างบัญชี แยกหมวดในรายการเดียว แท็ก กระทบยอด ยอดสะสม
- งบประมาณรายหมวด ยกยอดเหลือไปเดือนถัดไป คัดลอกงบเดือนก่อน
- รายการประจำที่ลงให้อัตโนมัติเมื่อถึงกำหนด
- รายงาน 5 แบบ — แยกตามหมวด รายรับ-รายจ่าย มูลค่าสุทธิ ร้านที่จ่ายมากสุด กระแสเงินสด
- นำเข้า/ส่งออก CSV สำรองและกู้คืนข้อมูล ล็อกด้วย PIN โหมดมืด ไทย-อังกฤษ

บนมือถือกด "เพิ่มไปยังหน้าจอโฮม" เพื่อใช้เหมือนแอพได้
